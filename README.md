# دربك | DARBAK

> **«رحلتك نحو صحة أفضل تبدأ من هنا.»**

منصة تثقيف صحي رقمية باللغة العربية، تهدف إلى مساعدة مرضى الأمراض المزمنة وأسرهم ومقدمي الرعاية، بالإضافة إلى الأشخاص ذوي الإعاقة، على الوصول إلى معلومات صحية موثوقة ومبسطة وسهلة الفهم.

---

## 🌟 مميزات المنصة

*   **محتوى طبي موثوق:** تغطية شاملة لخمسة أمراض مزمنة (السكري، ضغط الدم، أمراض القلب، الربو، أمراض الكلى) مع الإشارة إلى المصادر العلمية.
*   **اختبارات تثقيفية:** بنك أسئلة تفاعلي لقياس الوعي الصحي مع شرح لكل إجابة.
*   **محرك بحث ذكي:** بحث سريع في كافة محتويات المنصة مع دعم كامل للغة العربية (تجاهل التشكيل والهمزات).
*   **إمكانية الوصول (A11y):** قائمة جانبية متطورة تدعم:
    *   تكبير وتصغير الخط.
    *   التباين العالي (لضعاف البصر).
    *   القراءة الصوتية للنصوص (Text-to-Speech).
    *   تقليل الحركة والانتقالات.
*   **الوضع الليلي/الفاتح:** تصميم مريح للعين مع حفظ تفضيل المستخدم تلقائياً.
*   **تصميم متجاوب:** يعمل بسلاسة على الهواتف، الأجهزة اللوحية، والكمبيوتر.

---

## 🛠️ التقنيات المستخدمة

تم بناء المنصة لتكون خفيفة، سريعة، وقابلة للاستضافة على أي خدمة ويب ثابت (Static Hosting):

*   **HTML5** (هيكل الصفحات).
*   **CSS3** (تنسيقات مخصصة، متغيرات، وتصميم متجاوب).
*   **JavaScript (ES Modules)** (المنطق، التفاعل، وإدارة البيانات).
*   **JSON** (تخزين المحتوى الطبي والأسئلة بشكل منفصل عن الكود).
